# Sample files

Small test files for trying pixel-cast and for its tests, one set per matrix size: 8x8, 16x16 and 32x8 (32 wide,
8 high). They are generated by [`make_samples.py`](make_samples.py) (Pillow and ffmpeg) and carry no third-party
content; they are under the license of the repository.

| File | What it shows |
|---|---|
| `test-<size>.png` | a dimmed diagonal rainbow; one pure colour per corner (top-left red, top-right green, bottom-left blue, bottom-right white) for orientation; a transparent block in the centre, filled by `--background` |
| `test-<size>.gif` | a white dot bouncing off the edges with a short trail, over a background slowly changing hue; 40 frames of 50 ms, looping |
| `test-<size>.mp4` | H.264 (4:4:4), 30 fps, 3 s: a band of colour sweeping along the long side; the bottom row fills from the left as the video plays, so the end of a `--once` run is visible |

```bash
pixel-cast --host 192.0.2.50 --size 16x16 image samples/test-16x16.png --background 202020 --duration 10s
pixel-cast --host 192.0.2.50 --size 32x8 gif samples/test-32x8.gif
pixel-cast --host 192.0.2.50 --size 8x8 video samples/test-8x8.mp4 --loop
pixel-cast --size 16x16 --host 192.0.2.50 --dry-run gif samples/test-32x8.gif --fit cover
```

To make them again:

```bash
python3 samples/make_samples.py
```
