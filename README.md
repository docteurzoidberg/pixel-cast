# pixel-cast

A command-line tool that streams test patterns, still images, GIFs and videos to LED matrices over
**E1.31 (sACN)**. One self-contained binary per platform, meant to be driven by scripts and other tools as much as
by people.

**Status**: early development, nothing usable yet. See [`PLAN.md`](PLAN.md) for the design and the roadmap.
